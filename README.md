# AppManager

Windows 桌面应用管理器：应用列表、资源分类与集合、图片查看、内置视频播放、桌面收纳与备份。

软件页面只收录软件（程序、快捷方式、打包应用），只能通过「+ 添加」加入软件，不接受外部拖入、粘贴或新建文件：「+ 添加」列出本机已安装的软件（含 Office、应用商店应用），勾选后加入当前分类，原分类不变、不重复登记程序文件；Windows 自带的系统工具默认不列，打开「显示系统工具」后可选；便携程序等不在列表里的 exe 用「浏览其它程序…」登记。文件和文件夹的导入、复制、剪切、粘贴只在资源页面进行。桌面收纳只收软件快捷方式，指向文件夹或文档的快捷方式留在桌面。

## 拖放与拖影

条目越过系统拖动阈值后显示独立图标快照，位置跟随即时更新；多选时数量徽标使用实际拖放载荷，拖到其它程序时按已去重、可导出的路径计数。拖影使用不激活、不进入任务栏、鼠标命中的透明分层窗口，不抢占前台焦点。

拖放反馈区分三种语义：可执行操作为接受，原地排序、已属于目标分类或集合为中性，自嵌套、类型不符或不可接收目标为拒绝。网格内排序、目录搬迁、侧栏分类和集合共用同一套落点预检，松手时仍会再次校验。内部拖动按 Esc 只取消，不触发排序、搬迁或投放；拖出到其它程序后由系统 OLE 接管，Esc 和最终清理统一在 `DoDragDrop` 返回路径完成。`SetApps` 刷新、捕获丢失、`WM_CANCELMODE`、最小化和窗口销毁同样会结束并清理拖影及侧栏高亮。

## 集合文件夹

资源分类下的集合支持多层嵌套。进入集合后在内容区空白处右键选择「新建子文件夹…」，或在集合行右键、侧栏底栏创建；这些操作只创建集合归属，不会在磁盘上创建文件夹，也不会搬动资源文件。

侧栏按层级缩进显示，箭头可展开/收起；点击集合行取得键盘焦点后，可用上下键移动、左右键展开收起或回到父级、回车进入、空格切换展开状态。信息页的成员数只统计当前文件夹的直接成员，并单独显示直接子文件夹数量；集合内搜索也只匹配当前文件夹的直接成员。集合行可直接拖动排序：拖到目标行上下边缘调整同级顺序，拖到行中部移入该集合，拖到「全部」或右键「从母集合移出」回到当前资源分类的根目录；只能在当前分类内移动，不能移入其他资源分类。拖动反馈与松手使用同一套预检，原位置、拖到自身或当前父级不会保存。

数据库升级后不再支持旧版程序直接打开；含嵌套集合的 `.ambak` 备份也不支持降级导入，因为旧版会忽略父集合字段。需要回退时请使用升级前的完整备份。

## 搜索范围

软件/资源搜索只匹配当前模式。未进入集合时，搜索限定在左侧当前分类；在“全部软件/全部资源”中搜索则覆盖整个模式。进入集合后，搜索只匹配该集合的直接成员，不递归子集合。条目名称或所属分类/集合名称命中时都会返回结果，但不越出当前搜索范围。

## 图片格式

内置查看器支持 JPG/JPEG、PNG、GIF、BMP、WebP。RW2 通过系统 Windows Imaging Component 解码，需要安装 Microsoft Raw Image Extension；未安装时缩略图显示占位，打开文件会提示安装，不会回退到不支持 RAW 的 GDI+ 解码。RW2 的列表和属性页拍摄时间优先读取 EXIF `DateTimeOriginal`，再回退 `DateTimeDigitized`、`DateTime`；元数据读取不设文件大小上限，查看器仍保留像素总量保护。

## 视频格式

内置播放器支持 MP4、MKV、AVI、MOV、WMV、FLV、WebM、M4V 和 3GP（`.3gp`）。3GP 只是容器，能否播放取决于内部音视频编码；当前构建已验证 H.264/AAC、H.263/AMR-NB 和无音轨 3GP 样本，其他编码组合未做完整回归。

## 目录分离

- 开发目录：`D:\OWN Work\AppManager`，存放源码、Git 仓库、构建脚本和开发文档。
- 运行目录：`%LOCALAPPDATA%\AppManager`，存放 `AppManager.exe`、`libmpv-2.dll`、数据库、缓存、备份和日志。

`build.ps1` 默认将新构建发布到运行目录：先写入同目录暂存文件，自测和数据库回归通过后再原子替换。应用运行中会拒绝覆盖，构建前请先从托盘菜单退出。

## 资源存储位置

在“照片”分类的“+ 添加”菜单中可选择“整理本机照片…”。点击后先在一个清单里勾选扫描范围：清单分为常用文件夹（图片/桌面/下载）、磁盘（本地固定磁盘和已就绪的可移动磁盘）和用「添加文件夹…」加入的自定义文件夹，勾上即纳入扫描；默认只勾选“图片”，上次扫描的范围会恢复为勾选。自定义文件夹可点行尾的 × 移除，常用文件夹和磁盘只能取消勾选。网络位置、光驱、未就绪磁盘在清单里灰显并写明原因，链接/联接点目录不支持；父子目录和重复范围会合并，只扫描一次，被上级范围包含的行会标明“已包含在…中”。结果确认时可选择“移入资源库并清理原件”（推荐；成功项在数据库提交并逐项校验后永久删源，失败项保留）或“仅复制，保留原件”；删除不进入回收站，可移动磁盘或同步目录中的删除会同步生效，且移入模式不会由回车直接触发。两种模式都不新增或修改存储位置。已有资源存储位置和 AppManager 数据目录会跳过；已完成的复制/移动记录结合源长度、修改时间、目标身份和必要哈希避免重复扫描时再次制造副本；移动删源失败后仍在的源文件会显示为“已收录但原件待清理”，引导到导入记录重试。云端未下载的照片只计数、不读取内容。照片按 EXIF 拍摄时间归入“照片”分类下的“2025年”等集合，无拍摄时间时回退到文件修改时间。扫描结果确认框顶部是一句话结论和新增、已收录、云端未下载、读取失败四个数字，下方是可滚动的明细（跳过、失败示例和预计复制大小）；可继续收录、点「修改范围」回到范围清单（保留本次勾选），或按同一范围重新扫描。扫描可取消；扫描结束前关闭进度窗口等同取消，窗口会等后台扫描停止后才关闭。不可读目录和文件会汇总提示。为减少大容量整理时的卡顿，扫描处理最多约 100 张/秒，复制主数据和备用数据流合计限速约 32 MB/s，始终使用单个后台任务；普通手动导入不受此限速影响。

设置页的「资源存储位置」直接列出各资源存储根目录，可就地添加、启用/停用和调整顺序，改动立即保存；列表顺序就是导入时的优先顺序。同一卷内移动只用硬链接，不要求额外空间；复制或跨卷移动会先计算文件/文件夹大小，要求目标位置剩余空间至少再保留 1 GB。复制中途遇到磁盘满时，程序清理本批临时副本并改用下一个启用的位置，源文件保持不变；一个文件或文件夹不会拆分到多个位置。

停用某个位置后不再向它导入新文件，但仍会识别其中已有的库内文件；全部位置都停用时不接收新资源，也不会偷偷回退到默认目录。旧版单一路径会自动成为第一个启用位置，配置文件仍把第一个启用位置写入旧字段供旧版本读取。导入 `.ambak` 备份包时保留本机的位置列表。

## 本机视频扫描

资源页「视频」分类的「+ 添加」菜单提供「整理本机视频…」。扫描流程与照片一致：先在范围清单里勾选常用文件夹（视频/桌面/下载）、本地固定磁盘、已就绪的可移动磁盘或用「添加文件夹…」加入的自定义文件夹，默认只勾选“视频”；网络位置、光驱、未就绪磁盘灰显并写明原因，链接/联接点目录不支持，重复及父子范围会合并。扫描跳过回收站、现有资源存储位置和 AppManager 数据目录，可随时取消；云端未下载的视频只计数、不读取内容。

结果确认时可选择移入资源库（成功项删源、失败项保留）或仅复制保留原件，不新增或修改存储位置。已完成的复制/移动记录、已登记目标和目标改名后的来源路径都会复用，重复扫描不会再次制造副本；复用只接受与导入记录长度、修改时间、目标身份一致且必要时哈希一致的源文件，移动后的新同名文件会按新文件处理。已收录但删除源未完成的条目会在结果中明确标为“原件待清理”，需到导入记录重试。视频按 MP4/MOV/M4V 元数据中的创建时间归入“视频”分类下的年份集合，读取不到时回退到文件修改时间。结果确认框显示一句话结论、新增/已收录/云端未下载/读取失败四个数字和可滚动明细，可继续收录、点「修改范围」回到范围清单或按同一范围重新扫描；不可读目录和文件会汇总提示。扫描处理最多约 100 个/秒，复制主数据和备用数据流合计限速约 32 MB/s，始终使用单个后台任务。

## 本机音乐扫描

资源页「音乐」分类的「+ 添加」菜单提供「扫描本机音乐…」和「清理失效音乐记录…」。扫描前先在范围清单里勾选常用文件夹（音乐/桌面/下载）、本地固定磁盘、已就绪的可移动磁盘或用「添加文件夹…」加入的自定义文件夹，默认只勾选“音乐”；网络位置、光驱、未就绪磁盘灰显并写明原因，链接/联接点目录不支持，重复及父子范围会合并。扫描跳过回收站和 AppManager 数据目录，可随时取消。结果确认框显示一句话结论、可导入/无法确认/已收录/读取失败四个数字，以及含跳过、预计复制大小和识别原因的可滚动明细，可继续导入、点「修改范围」回到范围清单或按同一范围重新扫描，并选择移入资源库（成功项删源、失败项保留）或仅复制保留原件。导入日志中的复制记录和移动删源残留会结合源长度、修改时间、目标身份和必要哈希复用；已收录但原件待清理的条目会单独提示并引导到导入记录重试，移动后的新同名文件按新文件处理。资源复制仍登记原始来源路径；来源已在其他资源分类时只补音乐归属，用户主动排除的音乐保持排除。不可读位置在确认前汇总提示。扫描先按扩展名收集候选，再用 libmpv 读取时长、音频轨、声道/采样率和标签，按固定规则识别歌曲：跳过小于 64 KB、云端未下载、系统/程序/游戏库目录，以及播客/有声书/提示音/录音等；30 秒以下、无法解析或无法确认的文件不会自动收录，完成提示会按原因计数，并允许选择一并导入“无法确认”文件。播放组件缺失时默认取消，也可明确选择按扩展名继续。不同路径的相同歌曲仍可能分别收录，云端按需文件请先设为“始终保留在此设备上”再扫描。清理只移除原文件已不存在且父目录仍可访问的数据库记录，确认后二次复核；移动盘离线、网络断开时跳过，磁盘和回收站文件始终不动。

## 构建

要求：Windows 10/11 64 位（libmpv 仅提供 x64），.NET Framework 4.8（`csc.exe`），PowerShell 5.1。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

`build.ps1` 会编译 `src` 下全部源码为单文件 `AppManager.exe` 并发布到 `%LOCALAPPDATA%\AppManager\AppManager.exe`，随后运行内置自测（`--selftest`，当前 68 项），日志写入运行目录的 `selftest.log`。

分类、集合、内容关系、配置和操作记录存入本机 SQLite 数据库，首次启动自动迁移 XML 并保留原件。列表支持索引分页，设置页提供操作记录、撤销、完整备份和恢复。表结构、索引、升级和恢复说明见 [DATABASE.md](DATABASE.md)。构建还会运行隔离的数据库回归；`-ScaleDatabaseTests` 可额外验证 30 万条数据。

## 视频播放器依赖（libmpv-2.dll）

内置播放器通过 P/Invoke 调用 libmpv。`libmpv-2.dll` 是约 112MiB 的二进制，直接入库会让仓库体积膨胀并触及托管平台限制，因此不入库，由构建流程按需下载。

首次构建时如果缺少 `libmpv-2.dll`，`build.ps1` 会自动执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\fetch-libmpv.ps1
```

脚本行为：

1. 从 nuget.org 下载固定版本的 `Endpne.LibMPV.Windows 0.41.0` 包（约 78MiB）。
2. 校验整个包的 SHA256：`99811FA17D8D14C64C5F35A230D8F77FAAB63AAA85097F67D272F781E677C252`。
3. 解出包内 `build/x64/libmpv-2.dll`，校验 SHA256：`38ACD030006062830D792A958C5F2ADC293FA965996797980EC73D9610C309F4`。
4. 把 DLL 放到运行目录的 `AppManager.exe` 同目录。
5. 同步复制 `libmpv-LICENSE.txt` 到 DLL 同目录。

常用参数：

```powershell
# 已存在时跳过；-Force 强制重新下载覆盖
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\fetch-libmpv.ps1 -Force

# 输出到指定位置
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\fetch-libmpv.ps1 -Destination D:\path\libmpv-2.dll
```

离线或无法访问 nuget.org 时：

- 设置 `APPMANAGER_SKIP_LIBMPV_FETCH=1` 后再构建，构建会继续，但播放器显示占位提示。
- 手动从 <https://www.nuget.org/packages/Endpne.LibMPV.Windows/0.41.0> 下载 `.nupkg`，改名为 `.zip`，解出 `build/x64/libmpv-2.dll` 放到 `AppManager.exe` 同目录。
- libmpv 使用 LGPL 协议，许可文本见仓库根目录 `libmpv-LICENSE.txt`。
